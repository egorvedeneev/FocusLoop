# Ключевые вайрфреймы экранов

[Назад в README](../../README.md)

Этот документ определяет структурные вайрфреймы для пяти самых важных UX-поверхностей:

- `Сегодня`
- `Уточнение входящих`
- `Проекты`
- `Детали проекта`
- `Еженедельный обзор`

Цель не в визуальной полировке. Цель - в устойчивой информационной иерархии для веба и мобильного приложения.

## 1. Сегодня
### Вайрфрейм для веба
```text
+--------------------------------------------------------------------------------------+
| Верхняя панель: Дата | Сводка внимания | Поиск | Быстрый захват                      |
+----------------------+---------------------------------------------------------------+
| Левая панель         | Сегодня                                                    |
| - Сегодня            | ----------------------------------------------------------  |
| - Входящие           | Главная карточка: 3 элемента требуют внимания сегодня      |
| - Проекты            | [Начать с фоллоуапов] [Открыть активные проекты]          |
| - Фоллоуапы          |                                                            |
| - Еженедельный обзор | Секция A: Просроченные или вернувшиеся фоллоуапы          |
| - Справочник         | [Карточка проекта] [Карточка проекта] [Карточка проекта]  |
|                      |                                                            |
|                      | Секция B: Активные проекты без следующего действия        |
|                      | [Карточка проекта] [Карточка проекта]                     |
|                      |                                                            |
|                      | Секция C: Рекомендуемые следующие действия                |
|                      | [Карточка действия] [Карточка действия] [Карточка действия]|
|                      |                                                            |
|                      | Секция D: Входящие ожидают уточнения                      |
|                      | [Открыть входящие]                                         |
+----------------------+---------------------------------------------------------------+
```

### Вайрфрейм для мобильного
```text
+----------------------------------+
| Сегодня             [Захват]     |
+----------------------------------+
| Главное: 3 элемента требуют внимания|
| [Проверить сейчас]               |
+----------------------------------+
| Вернувшиеся фоллоуапы            |
| [Карточка]                       |
| [Карточка]                       |
+----------------------------------+
| Нет следующего действия          |
| [Карточка]                       |
+----------------------------------+
| Рекомендуемые следующие шаги     |
| [Карточка]                       |
| [Карточка]                       |
+----------------------------------+
| Входящие ожидают                 |
| [Открыть 5 элементов]            |
+----------------------------------+
| Нижняя навигация                 |
+----------------------------------+
```

### Список компонентов
- главная карточка со сводкой
- секции внимания с ярлыками причин
- компактные карточки проектов
- карточки следующего действия
- баннер статуса входящих

### Основное действие
- `Проверить сейчас`

## 2. Уточнение входящих
### Вайрфрейм для веба
```text
+--------------------------------------------------------------------------------------+
| Левая панель | Входящие                                                              |
+----------------------------+---------------------------------------------------------+
| Очередь входящих           | Уточнение выбранного элемента                           |
| -------------------------  | ----------------------------------------------------- |
| [Письмо от Анны]           | Предпросмотр сырого ввода                              |
| [Заметка со встречи]       | "Нужно проверить сроки по сервису с бэкенд-командой"  |
| [Сообщение из Telegram]    |                                                       |
| [Идея, захваченная с моб.] | Что это?                                              |
|                            | [Новый проект] [Следующее действие] [Заблокировано]   |
|                            | [Справочник]                                          |
|                            |                                                       |
|                            | Область динамической формы                            |
|                            | - заголовок / цель                                    |
|                            | - первое следующее действие                           |
|                            | - блокер и дата возврата, если нужно                 |
|                            |                                                       |
|                            | [Сохранить и далее]        [Архивировать]             |
+----------------------------+---------------------------------------------------------+
```

### Вайрфрейм для мобильного
```text
+----------------------------------+
| Входящие                 [5]     |
+----------------------------------+
| Карточка 1 из 5                  |
| "Нужно проверить сроки по        |
| сервису с бэкенд-командой"       |
|                                  |
| Что это?                         |
| [Новый проект]                   |
| [Следующее действие]             |
| [Заблокировано]                  |
| [Справочник]                     |
+----------------------------------+
| [Архивировать] [Продолжить]      |
+----------------------------------+
```

### Вайрфрейм шага фоллоуапа
```text
+----------------------------------+
| Создать заблокированный фоллоуап |
+----------------------------------+
| Ожидаем                          |
| [Анна Петрова              ]     |
| Блокер                           |
| [Нужна оценка срока по API]      |
| Дата возврата                    |
| [20 апр                    ]     |
| Действие фоллоуапа               |
| [Напомнить Анне в чате     ]     |
+----------------------------------+
| [Сохранить и далее]              |
+----------------------------------+
```

### Основное действие
- `Сохранить и далее`

## 3. Проекты
### Вайрфрейм для веба
```text
+--------------------------------------------------------------------------------------+
| Левая панель | Проекты                                                               |
+-----------------------------+--------------------------------------------------------+
| Сегменты: Активные          | Контекстная панель                                    |
| Заблокированные Завершённые | ----------------------------------------------------- |
|                             | Название проекта                                      |
| [Карточка проекта]          | Бейдж статуса                                         |
| следующее действие / устарел| Текущее следующее действие                            |
| [Карточка проекта]          | Последнее движение                                    |
| [Карточка проекта]          | Ожидаем / дата возврата, если заблокирован           |
|                             | Связанные люди                                        |
| Фильтры:                    | [Открыть полные детали]                               |
| - нет следующего действия   |                                                       |
| - устаревшие                |                                                       |
| - заблокированы на этой нед.|                                                       |
+-----------------------------+--------------------------------------------------------+
```

### Вайрфрейм для мобильного
```text
+----------------------------------+
| Проекты                [+]       |
+----------------------------------+
| [Активные] [Заблок.] [Готово]    |
+----------------------------------+
| Поиск по проектам                |
+----------------------------------+
| [Карточка проекта]               |
| [Карточка проекта]               |
| [Карточка проекта]               |
+----------------------------------+
| Нижняя навигация                 |
+----------------------------------+
```

### Анатомия карточки проекта
- заголовок
- индикатор статуса
- текущее следующее действие или ярлык отсутствующего состояния
- ярлык причины, если карточка показана логикой внимания
- небольшая строка метаданных: последнее движение, ожидание, дата возврата

### Основное действие
- `Открыть проект`

## 4. Детали проекта
### Вайрфрейм для веба
```text
+--------------------------------------------------------------------------------------+
| Хлебные крошки / Проекты / Миграция Payments API                    [Заблокировать] |
+--------------------------------------------------------------------------------------+
| Заголовок: название | статус | последнее движение | связанные сущности               |
+------------------------------------+-------------------------------------------------+
| Карточка следующего действия       | Вкладки активности / заметок / контекста        |
| ---------------------------------  | ----------------------------------------------  |
| Текущий следующий шаг              | Журнал активности                                |
| "Уточнить у инфраструктурной ..." | - следующее действие обновлено                   |
|                                    | - заблокировано 18 мар                           |
| [Завершить] [Изменить следующее]   | - фоллоуап отправлен                             |
|                                    |                                                 |
| Карточка внимания                  | Заметки                                          |
| "Нет движения 7 дней"              |                                                 |
|                                    | Связанные сущности                               |
| Сводка блокировки, если актуально  | - Анна Петрова                                   |
| ожидание / дата возврата / причина | - Команда Payments                               |
+------------------------------------+-------------------------------------------------+
```

### Вайрфрейм для мобильного
```text
+----------------------------------+
| Назад   Детали проекта           |
+----------------------------------+
| Миграция Payments API            |
| Активен | Последнее движение 2д  |
+----------------------------------+
| Следующее действие               |
| Уточнить срок у инфраструктуры   |
| [Завершить] [Изменить]           |
+----------------------------------+
| Внимание                         |
| Нет движения 7 дней              |
+----------------------------------+
| Ожидание / связи / активность    |
| [секции друг под другом]         |
+----------------------------------+
| Закреплённая панель действий     |
| [Блокировать] [Добавить заметку] |
+----------------------------------+
```

### Основное действие
- `Завершить следующее действие`

## 5. Еженедельный обзор
### Вайрфрейм для веба
```text
+--------------------------------------------------------------------------------------+
| Левая панель | Еженедельный обзор                                                    |
+---------------------------------+----------------------------------------------------+
| Выбор недели                   | Заголовок сводки                                    |
| [Эта неделя v]                 | 6 проектов сдвинулись | 2 заблок. | 3 устарели     |
|                                 |                                                    |
| Секции обзора                   | Продвинулись вперёд                                 |
| - Продвинулись вперёд           | [Строка проекта] [Строка проекта]                   |
| - Всё ещё заблокированы         |                                                    |
| - Без движения                  | Всё ещё заблокированы                               |
| - Нет следующего действия       | [Строка проекта] [Строка проекта]                   |
|                                 |                                                    |
|                                 | Без движения                                        |
|                                 | [Строка проекта] [Строка проекта]                   |
|                                 |                                                    |
|                                 | Нет следующего действия                             |
|                                 | [Строка проекта] [Строка проекта]                   |
+---------------------------------+----------------------------------------------------+
```

### Вайрфрейм для мобильного
```text
+----------------------------------+
| Обзор                            |
+----------------------------------+
| Эта неделя                       |
| 6 сдвинулись | 2 заблок. | 3 уст.|
+----------------------------------+
| Шаг 1: Успехи                    |
| [Строки проектов]                |
| [Продолжить]                     |
+----------------------------------+
| Шаг 2: Всё ещё заблокированы     |
| [Строки проектов]                |

+----------------------------------+

| [Строки проектов]                |

| [Строки проектов]                |
| [Завершить обзор]                |
+----------------------------------+
```

### Основное действие
- `Продолжить обзор`

## Общие правила карточек
- Заголовок карточки по возможности всегда занимает одну строку.
- Причина внимания располагается над метаданными и под заголовком.
- В контексте списков относительное время предпочтительнее точных таймстампов.
- Цвет статуса никогда не должен быть единственным сигналом; добавляйте иконку или ярлык.
- Если следующего действия нет, область действия заменяется корректирующей подсказкой.

## Порядок приоритета экранов
1. `Сегодня`
2. `Уточнение входящих`
3. `Детали проекта`
4. `Проекты`
5. `Еженедельный обзор`

Этот порядок отражает ожидаемую частоту ежедневного использования.
